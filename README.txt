THE MCGANN LABORATORY WEBSITE
=============================

This is a static website built with HTML, CSS, and a small amount of JavaScript.
It does not require a database, build tool, or server-side application.

FILES
-----
index.html          Home / landing page
publications.html   Publications page (includes sourced bibliography entries)
people.html         People page (ready for team information)
styles.css          Shared styling and responsive layout
script.js           Mobile navigation and automatic copyright year
assets/             Image assets, including the research image and John McGann portrait

PREVIEW LOCALLY
---------------
Extract the ZIP, then open index.html in a web browser.

HOSTING
-------
Upload the contents of this folder to your web host's public web directory.
Keep the relative folder structure intact, including the assets folder.

ADDING YOUR IMAGES
------------------
The home page uses assets/sensory-neuroscience.jpg as its research image and
assets/john-mcgann.jpg for the Principal Investigator profile. Replace either file
with an updated image of the same filename, or change the corresponding image path
in index.html. Add image credits if required.

------
The site uses Rutgers-inspired scarlet (#cc0033), black, white, and gray.
The design is inspired by Rutgers colors and is not an official Rutgers template.
